# Anil Herenj - Developer Portfolio

A modern, responsive portfolio website built with Next.js, React, and Tailwind CSS to showcase my projects, skills, and experience.

🚀 Live Demo: [Anil Herenj Portfolio](https://anilheranj.github.io/Anil-portfolio/)

---

## Features

- **Modern UI/UX:** Built with Tailwind CSS and Framer Motion for smooth animations and micro-interactions.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
- **Interactive Contact Form:** Powered by EmailJS for direct messaging.
- **Clean Architecture:** Organized component structure using Next.js.

---

## Tech Stack

- **Framework:** Next.js / React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Services:** EmailJS
